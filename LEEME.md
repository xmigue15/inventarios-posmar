# Inventario MercadoLibre (fase 1)
1. Ejecuta supabase.sql en Supabase (SQL Editor).
2. Sube estos archivos a la raíz del repositorio de GitHub.
3. En Vercel > Settings > Environment Variables agrega las variables de .env.example.
4. Redeploy. Entra a la app, pon la clave, pulsa "Conectar MercadoLibre" y luego "Sincronizar ahora".
